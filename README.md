# VarlikeReader

VarlikeReader 是一款专为 VS Code 打造的沉浸式小说阅读与本地 JSON 数据库可视化插件。

## ✨ 功能特性

### 📖 沉浸式小说阅读
- **专为 TXT 优化**：一键将杂乱的 TXT 文件排版为干净的阅读界面。
- **智能分章**：自动识别“第 X 章”、“序章”等格式，生成目录导航。
- **排版优化**：自动去除多余空行，首行缩进，支持自定义字体大小与行间距。
- **护眼模式**：内置深色/护眼切换，保护视力。

### 🗄️ JSON 关系型数据库
- **可视化操作**：像使用 Navicat 一样在 VS Code 中创建 Schema、Table 和 Column。
- **丰富的数据类型**：支持 `int8`、`int16`、`int32`、`long`、`float`、`double`、`boolean`、`string`、`enum`（全局枚举）以及 `global_index`（全局自增索引）。
- **快捷编辑**：双击单元格直接修改，回车保存。
- **外部联动**：生成的 JSON 数据库结构极其规范，可无缝供 Godot 等外部游戏引擎直接读取。

### 🌳 JSON 树状阅读器
- 告别满屏的 `{}` 和 `[]`，提供带语法高亮、支持无限折叠的树状视图。
- 支持实时搜索 Key 或 Value，自动高亮并展开匹配节点。

## 🚀 快速开始

1. 在 VS Code 左侧活动栏点击 **VarlikeReader** 图标。
2. 点击 **"TXT文件打开为Novel"** 开始阅读，或点击 **"打开数据库控制台"** 管理你的 JSON 数据。
